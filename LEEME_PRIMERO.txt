🚀 INICIO RÁPIDO (3 PASOS):

  1. Instala MongoDB
     → https://www.mongodb.com/try/download/community
     O usa Docker:
     → docker run -d -p 27017:27017 --name mongodb mongo:7-alpine

  2. Ejecuta el Backend
     → Abre PowerShell/CMD
     → cd backend
     → npm run dev

  3. Ejecuta el Frontend (en otra terminal)
     → cd C:\Users\leoni\OneDrive\Escritorio\Proyects\to-do-app
     → pnpm dev

  4. Abre tu navegador
     → http://localhost:5173
